# Team America

A Runtime Republic Study Circle. The name is temporary until the members choose one.

This repository is public. It holds group information only: counts, reviewed study files and meeting notes. No member's personal finances, ever.

## Join Team America

[Join Team America](https://github.com/RuntimeRepublic/Team-America/issues/new?template=join.yml)

You need a free GitHub account and an AI (Claude free works). Takes about 15 minutes.

Steps: [ONBOARDING.md](ONBOARDING.md)

## Post team news

[Post a win, finding or problem](https://github.com/RuntimeRepublic/Team-America/issues/new?template=team-news.yml): Saturday posts, mid-week posts, findings and issues. How it works: [news/README.md](news/README.md)

| Path | Holds |
|---|---|
| packets/ | Each member's weekly team packet (call signs only) |
| data/group-counts.csv | Weekly team totals for the dashboard |
| data/study/ | Study files each member reviewed and pushed by hand |
| members/ | One file per member, written by the onboarding bot |
| news/ | Team goals and team news (wins, findings, issues) |
| DATA-RULES.md | What may and may not go in this repository |
| MEMBERS.md | Members who said yes to being listed, and the team's admins |
| ONBOARDING.md | How a new member joins |
| Work-Cards/ | Work card register for this repository |

Government data this team uses: [Gov-US](https://github.com/RuntimeRepublic/Gov-US), [Gov-KS](https://github.com/RuntimeRepublic/Gov-KS), [Gov-KS-Sedgwick-County](https://github.com/RuntimeRepublic/Gov-KS-Sedgwick-County).
