# Team packets

One file per member per week: `packets/<YYYY>-W<ww>/<CallSign>.csv`, for example `packets/2026-W48/Longbow.csv`.

- Format: [Formats/TEAM-PACKET.md](https://github.com/RuntimeRepublic/Runtime-Republic-Controls/blob/main/Formats/TEAM-PACKET.md) in Runtime-Republic-Controls.
- Your **Personal Finance project** writes the packet at Saturday close. You read it, then add it here by pull request. Your Team project never sees your finances.
- Call signs only. Flags use IDs from the [shared flag log](https://github.com/RuntimeRepublic/RuntimeRepublic.github.io/blob/main/images/flags/FLAG-LOG.csv).
- Read [DATA-RULES.md](../DATA-RULES.md) before your first packet.
